# Platform icons

Official social platform icons used across the app (creator headers, filters, login buttons, media kit).

- `twitch.png` — Twitch
- `youtube.png` — YouTube
- `instagram.png` — Instagram
- `tiktok.png` — TikTok
- `x.png` — X (Twitter)

Sizing is handled by the shared `PlatformIcon` component (`@/components/shared/PlatformIcon`), which uses these assets for the above platforms and falls back to a letter-in-circle for others (e.g. Kick).
